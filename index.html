Multi-Level Resource Management in 5G Network Slicing:
Spectrum, Power and NOMA

Eya Arouri | Advisor: Prof. Yoo Younghwan | Department of Information Convergence Engineering

01

Abstract

Radio access network (RAN) slicing requires the slice controller to continuously partition resources such as physical resource blocks (PRBs) and transmit power so that each slice meets its service-level agreement (SLA). A recent kernel-based reinforcement-learning (KBRL) controller achieves cold-start safety on this problem and outperforms standard deep-reinforcement-learning baselines, but operates over a one-dimensional action space (PRBs only) and assumes a physics-free mMTC channel. This thesis extends KBRL along two axes, enlarged from PRB count to the joint (PRB count, per-PRB power) pair. An intra-slice non-orthogonal multiple-access (NOMA) controller is added for both eMBB and mMTC slices: UEs are paired by SINR gap and a deep Q-network selects each pair's power-split coefficient under successive interference cancellation. A 3GPP-compliant mMTC channel with QPSK demodulation threshold and SIC failure cascade replaces the physics-free mMTC layer of the original simulator. Across 30 seeds of three scenarios, the proposed 2D KBRL + NOMA controller reduces mean transmit power by 30–32 % and PRB occupation by 4–5 % relative to the 1D KBRL baseline at identical workloads while still maintaining the SLA requirements of each slice.

02

Methodology

The framework decomposes radio-resource management into two control loops running at different timescales and couples them through a single binary SLA signal. A slow inter-slice controller decides, once every T_step TTIs, how many PRBs and how much transmit power each slice receives. A fast intra-slice controller then decides, every TTI, how each slice uses that budget to serve its own users. The two levels exchange only the allocation (downward) and the next observation plus the SLA outcome (upward), which lets each level be designed and analysed independently.

LEVEL 1
Inter-Slice Controller — Two-Dimensional KBRL
Allocates the joint pair (PRBs, power-per-RB) to each slice · runs every T_step TTIs
↓   allocation (rᵢ, pᵢ)
LEVEL 2
Intra-Slice Controller — NOMA Pairing + DQN Power Split
Pairs UEs by SNR gap, a DQN selects each pair's power-split α, SIC at the receiver · runs every TTI
↑   aggregate KPIs → SLA indicator
FEEDBACK
SLA Evaluation & Online Learning

Level 1 — Two-Dimensional KBRL

The original kernel-based reinforcement-learning controller acts on a one-dimensional action (PRB count only). This work extends the action to the joint pair (r, p) — the number of PRBs and the power assigned to each PRB — drawn from a finite power grid. Rather than learning the full system dynamics, each slice trains an online Projectron classifier that predicts whether a candidate allocation will satisfy that slice's SLA, and the controller selects the cheapest allocation predicted safe. Three modules run per decision stage: an H-learner that updates the classifiers using L-shape augmentation to preserve monotonicity across both resource axes, an E-learner that tracks per-axis classifier reliability through a security margin, and a controller that performs a decoupled two-phase search — minimising PRBs first, then trimming power-per-RB at that PRB count.

Level 2 — Learned NOMA Scheduling

Inside each slice, users are paired by an SNR-gap heuristic (strongest-with-weakest), and a deep Q-network selects each pair's power-splitting coefficient α, allocating at least half the per-PRB power to the weaker user so that successive interference cancellation (SIC) at the stronger user is well-posed. SIC failure is modelled explicitly — via a Bernoulli draw on a link-level reception curve for eMBB, and a hard QPSK demodulation threshold for mMTC. Users that cannot be paired fall back to a proportional-fair OMA scheduler. The DQN learns online from per-TTI rewards and requires no offline pre-training.

3GPP-Compliant mMTC Channel Model

The original simulator advanced mMTC repetition counters deterministically with no SINR check. This work replaces that physics-free layer with a per-sensor SNR model built on 3GPP TS 36.942 outdoor path loss, indoor-penetration offsets repurposed from the NB-IoT coverage classes of 3GPP TR 45.820, and a QPSK demodulation threshold. Failed decoding now keeps sensors in the queue across retry slots, so transmission failures and retransmissions genuinely affect resource decisions — making the inter-slice power axis actionable at the link level.

03

Performance & Results

The proposed 2D KBRL + NOMA controller was evaluated against the 1D KBRL baseline and seven deep-RL baselines (NAF, PPO1, PPO2, TRPO, A2C, TD3, SAC) on the same simulator, scenarios, and SLA bounds. Each algorithm was run for 30 independent seeds across three scenarios, with a learning phase of 40,000 decision stages from a cold start.

Key Findings

  • Power efficiency. Joint spectrum–power allocation cuts mean transmit power by roughly 30–32% with no SLA penalty, because a slice can meet its SLA with fewer PRBs at higher power or more PRBs at lower power — and the controller finds the cheaper mix.
  • Fewer overflow adjustments. The 2D controller lands inside the per-scenario budget more often, so the overflow projector trims less: 0.16 vs 0.24 (S1), 0.12 vs 0.17 (S2), 0.08 vs 0.09 (S3).
  • Higher classifier accuracy. The richer 2D action space lets the H-learner separate safe from unsafe allocations more reliably: 0.955 vs 0.943 (S1), 0.979 vs 0.967 (S2), 0.993 vs 0.986 (S3).
  • Cold-start safety preserved. The online-learning safety property that distinguishes KBRL from the deep-RL family survives the two-dimensional extension.
  • An honest trade-off. The 3GPP-compliant mMTC layer counts decoding failures and retransmissions that the 1D simulator never modelled, so reducing per-RB power can push some sensors near the decoding threshold. The resulting raw-violation increase reflects the price of physical realism, not a control regression — and it makes the energy-efficiency-versus-reliability trade-off observable for the first time.
